---
'@vapor-ui/style-macro': minor
---

`css()` now returns a plain string (RSC-safe) and merges compositions with the Compiled-style `_ax` group encoding. CSS is no longer emitted per file: every `css()` rule in the project is collected into one globally sorted sheet at `@vapor-utilities;`, so `@media` / pseudo / longhand overrides from one file always beat base rules from another regardless of bundler chunk order. The sheet is appended to the CSS file that imports `@vapor-ui/core/layers.css`, so the default setup needs no extra line. When you declare the layer order manually, write `@vapor-utilities;` once in your CSS entry instead. With PostCSS, register `vaporPostcss` before postcss-import (or write the marker); it warns when a file declares the Vapor layer order but has no insertion point. `include` is now a glob `string[]` (plus `exclude`, `root`); globs resolve against the bundler project root and may use `../` or absolute paths. Adds `@vapor-ui/style-macro/css-loader` and `@vapor-ui/style-macro/postcss`.
