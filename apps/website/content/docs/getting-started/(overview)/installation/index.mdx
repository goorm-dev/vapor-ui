이 문서를 완료하면 Vapor UI 패키지를 설치하고, 첫 번째 컴포넌트를 화면에 렌더링할 수 있습니다.

## 사전 준비

다음 환경이 필요합니다.

| 요구사항 | 버전    |
| :------- | :------ |
| React    | 17 이상 |
| Node.js  | 16 이상 |

## 1단계: 패키지 설치

패키지 매니저를 사용하여 Vapor UI를 설치합니다.

```package-install
npm install @vapor-ui/core @vapor-ui/icons
```

## 2단계: CSS 불러오기

애플리케이션의 최상위 CSS 파일(예: `global.css`, `styles.css`)에 Vapor UI 스타일을 추가합니다.

```css title="global.css"
@import '@vapor-ui/core/layers.css';
@import '@vapor-ui/core/styles.css';
```

| 엔트리                      | 내용                                                                                 |
| --------------------------- | ------------------------------------------------------------------------------------ |
| `@vapor-ui/core/layers.css` | `vapor-theme`, `vapor-reset`, `vapor-components`, `vapor-utilities` 레이어 순서 선언 |
| `@vapor-ui/core/styles.css` | `@property` 전역 변수 + 테마 토큰 + reset 스타일                                     |

프로젝트에서 이미 CSS Cascade Layer를 사용 중이거나 외부 라이브러리와 레이어 순서를 섞어야 한다면 `layers.css` 를 import 하지 않고 최상위 CSS에서 `@layer ...;` 선언으로 순서를 직접 지정할 수 있습니다. 자세한 내용은 [CSS Layers 가이드](../../handbook/css-layers) 를 참고하세요.

## 3단계: Portal 설정

Vapor UI는 Dialog, Popover 같은 팝업 컴포넌트에 Portal을 사용합니다. Portal 컴포넌트가 항상 페이지 최상단에 표시되도록 애플리케이션 레이아웃 루트에 다음 스타일을 추가합니다.

```tsx title="layout.tsx"
<body>
    <div className="root">{children}</div>
</body>
```

```css title="styles.css"
.root {
    isolation: isolate;
}
```

이 스타일은 `.root` 요소에 별도의 stacking context를 생성합니다. 이를 통해 팝업이 항상 페이지 콘텐츠 위에 표시되며, 다른 스타일의 `z-index` 속성과 충돌하지 않습니다.
