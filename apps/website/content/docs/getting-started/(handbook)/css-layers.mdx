Vapor UI는 모든 컴포넌트 스타일에 [CSS Cascade Layer](https://developer.mozilla.org/en-US/docs/Web/CSS/@layer)를 도입하여, 우선순위 충돌을 예방합니다. 기본 사용 방법과 레이어 순서를 직접 지정하는 방법을 소개합니다.

## 레이어 구성

Vapor UI는 총 다섯 개의 레이어로 구성됩니다. 아래로 갈수록 우선순위가 높습니다.

| 레이어             | 포함 스타일                                                               |
| ------------------ | ------------------------------------------------------------------------- |
| `vapor-theme`      | 테마 토큰(`--vapor-color-*` 등)과 라이트, 다크 테마 바인딩                |
| `vapor-reset`      | `*`, `html`, `body` 등에 적용되는 전역 Reset CSS                          |
| `vapor-components` | `@vapor-ui/core` 컴포넌트 내부 스타일                                     |
| `composites`       | `@vapor-ui/composites` 컴포넌트 내부 스타일                               |
| `vapor-utilities`  | `$css`나 `@vapor-ui/style-macro` 의 `css()` 유틸리티 함수가 생성한 스타일 |

## 기본 사용

프로젝트의 전역 CSS 파일에 다음 두 줄을 추가합니다.

```css title="globals.css"
@import '@vapor-ui/core/layers.css';
@import '@vapor-ui/core/styles.css';
```

| 엔트리                      | 내용                                                                                                 |
| --------------------------- | ---------------------------------------------------------------------------------------------------- |
| `@vapor-ui/core/layers.css` | 레이어 순서 지정 — `@layer vapor-theme, vapor-reset, vapor-components, composites, vapor-utilities;` |
| `@vapor-ui/core/styles.css` | `@property` 전역 변수 + 디자인 토큰 + Reset CSS                                                      |

### CSS 진입점은 가장 먼저 import 하세요

브라우저는 레이어 이름이 **등장한 순서**대로 레이어를 등록합니다. 나중에 `@layer ...;`를 선언해도 이미 등록된 순서를 바꿀 수 없습니다. `@vapor-ui/core`, `@vapor-ui/composites` 컴포넌트에는 CSS Cascade Layer 선언이 포함되어 있기 때문에, 컴포넌트를 CSS 진입점보다 먼저 import 하면 레이어가 의도와 다른 순서로 등록됩니다.

예를 들어 `composites` 가 `vapor-utilities` 뒤에 등록되면 `css()` 로 작성한 앱 스타일이 composites 스타일에 오버라이드 됩니다.

```tsx title="src/main.tsx"
// ✅ CSS 진입점이 모든 Vapor UI import 보다 먼저
import './styles.css';

import { AlertDialog } from '@vapor-ui/composites';
import { Button, ThemeProvider } from '@vapor-ui/core';
```

```tsx title="src/main.tsx"
// ❌ 컴포넌트 CSS가 먼저 로드되어 레이어 순서가 어긋남
import { ThemeProvider } from '@vapor-ui/core';

import './styles.css';
```

따라서 린터나 포매터 등을 이용하여 import 순서를 정렬하는 경우, [Side effect import](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Statements/import#import_a_module_for_its_side_effects_only)를 가장 먼저 배치하도록 설정하는 것을 권장합니다.

## 레이어 순서 커스터마이징

외부 CSS 라이브러리(Tailwindcss, 자체 디자인 시스템 등)와 함께 사용하는 경우, `layers.css`를 import 하지 않고 레이어 순서를 직접 선언하여 세부적인 커스터마이징을 할 수 있습니다.

```css title="globals.css"
/* 1. 최상위에서 레이어 우선순위 직접 선언 */
@layer app-base, vapor-theme, vapor-reset, app-components, vapor-components, composites, vapor-utilities, app-utilities;

/* 2. Vapor UI 디자인 토큰 + Reset CSS */
@import '@vapor-ui/core/styles.css';

/* 3. 외부 라이브러리 또는 자체 CSS */
@import 'your-library/base.css' layer(app-base);
@import './app.css';
```

이 경우에도 마찬가지로 호출된 순서에 따라 Cascade Layer 우선순위가 지정되므로, 반드시 `@layer` 선언이 최상위에 위치해야 합니다.

## 프레임워크별 예시

### Next.js (App Router)

```css title="app/globals.css"
@import '@vapor-ui/core/layers.css';
@import '@vapor-ui/core/styles.css';
```

```tsx title="app/layout.tsx"
import './globals.css';

export default function RootLayout({ children }: { children: React.ReactNode }) {
    return (
        <html lang="ko">
            <body>{children}</body>
        </html>
    );
}
```

### Vite

```css title="src/styles.css"
@import '@vapor-ui/core/layers.css';
@import '@vapor-ui/core/styles.css';
```

```tsx title="src/main.tsx"
import './styles.css';

import { StrictMode } from 'react';
import { createRoot } from 'react-dom/client';

import App from './App';

createRoot(document.getElementById('root')!).render(
    <StrictMode>
        <App />
    </StrictMode>,
);
```
