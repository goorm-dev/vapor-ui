Vapor UI는 모든 컴포넌트 스타일을 [CSS Cascade Layer](https://developer.mozilla.org/en-US/docs/Web/CSS/@layer) 로 감싸 priority 충돌을 예방합니다. 기본 사용 방법과 레이어 순서를 직접 지정하는 방법을 소개합니다.

## 레이어 구성

Vapor UI는 네 개의 레이어를 사용합니다. 아래로 갈수록 우선순위가 높습니다.

| 레이어             | 포함 스타일                                          |
| ------------------ | ---------------------------------------------------- |
| `vapor-theme`      | 테마 토큰(`--vapor-color-*` 등)과 라이트/다크 바인딩 |
| `vapor-reset`      | `*`, `html`, `body` 등에 적용되는 전역 reset         |
| `vapor-components` | 각 컴포넌트의 base, variant, recipe 스타일           |
| `vapor-utilities`  | Sprinkles · Tailwind preset 유틸리티                 |

## 엔트리 구성

| 엔트리                      | 내용                                                                                                    |
| --------------------------- | ------------------------------------------------------------------------------------------------------- |
| `@vapor-ui/core/layers.css` | 레이어 순서 선언만 포함 — `@layer vapor-theme, vapor-reset, vapor-components, vapor-utilities;` 과 동일 |
| `@vapor-ui/core/styles.css` | `@property` 전역 변수 + 테마 토큰 + reset 스타일                                                        |

두 파일 모두 import 하는 것이 기본이며, 외부 라이브러리와 레이어 순서를 섞어야 하는 경우에만 `layers.css` 를 생략하고 최상위에서 `@layer ...;` 를 직접 선언합니다.

## 기본 사용

애플리케이션 최상위 CSS 파일에 다음 두 줄을 추가합니다.

```css title="global.css"
@import '@vapor-ui/core/layers.css';
@import '@vapor-ui/core/styles.css';
```

`layers.css` 가 먼저 import 되어 레이어 순서를 확정한 뒤, `styles.css` 의 토큰과 reset 이 각 레이어에 올바르게 배치됩니다.

## 레이어 순서 커스터마이징

외부 CSS 라이브러리(Tailwind, 자체 디자인 시스템 등)와 섞어 쓰면서 특정 레이어를 Vapor UI 위/아래에 두어야 한다면 `layers.css` 를 import 하지 않고 최상위에서 레이어 순서를 직접 선언합니다.

```css title="global.css"
/* 1. 최상위에서 레이어 우선순위 직접 선언 (layers.css 생략) */
@layer app-base, vapor-theme, vapor-reset, app-components, vapor-components, vapor-utilities, app-utilities;

/* 2. Vapor UI 토큰 + reset */
@import '@vapor-ui/core/styles.css';

/* 3. 외부 라이브러리 또는 자체 CSS */
@import 'your-library/base.css' layer(app-base);
@import './app.css';
```

`@layer` 선언이 최초로 등장한 순서가 cascade 우선순위를 결정하므로, 최상위 CSS 파일의 `@layer ...;` 는 `@import` 보다 먼저 와야 합니다.

## 프레임워크별 예시

### Next.js (App Router)

```css title="app/globals.css"
@import '@vapor-ui/core/layers.css';
@import '@vapor-ui/core/styles.css';
```

```tsx title="app/layout.tsx"
import './globals.css';

export default function RootLayout({ children }: { children: React.ReactNode }) {
    return (
        <html lang="ko">
            <body>{children}</body>
        </html>
    );
}
```

### Vite

```css title="src/styles.css"
@import '@vapor-ui/core/layers.css';
@import '@vapor-ui/core/styles.css';
```

```tsx title="src/main.tsx"
import './styles.css';

import { StrictMode } from 'react';
import { createRoot } from 'react-dom/client';

import App from './App';

createRoot(document.getElementById('root')!).render(
    <StrictMode>
        <App />
    </StrictMode>,
);
```

### Storybook

```css title=".storybook/global.css"
@import '@vapor-ui/core/layers.css';
@import '@vapor-ui/core/styles.css';
```

```ts title=".storybook/preview.ts"
import './global.css';
```

## v1 → v2 마이그레이션

v1 에서는 `ThemeProvider` import 가 CSS 를 자동으로 주입했습니다. v2 부터는 자동 주입이 사라지므로, 애플리케이션 CSS 파일에 직접 import 를 추가해야 합니다.

```diff title="app/globals.css"
+ @import '@vapor-ui/core/layers.css';
+ @import '@vapor-ui/core/styles.css';
```

이 변경 이후 컴포넌트가 스타일 없이 렌더링된다면 위 import 가 누락되지 않았는지 확인하세요.
