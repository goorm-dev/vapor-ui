### Display Types

Box 컴포넌트는 다양한 디스플레이 타입을 지원하여 레이아웃을 유연하게 구성할 수 있습니다.

<Demo file="/content/docs/components/(layouts)/box/demos/box-display.tsx" />

### Background Color

Box 컴포넌트는 시맨틱 색상과 팔레트 색상을 모두 지원합니다.

<Demo file="/content/docs/components/(layouts)/box/demos/box-background.tsx" />

### Spacing

패딩과 마진 속성을 사용하여 요소의 내부 및 외부 여백을 조절할 수 있습니다.

<Demo file="/content/docs/components/(layouts)/box/demos/box-spacing.tsx" />

### Layout

플렉스박스 속성을 활용하여 다양한 레이아웃을 구성할 수 있습니다.

<Demo file="/content/docs/components/(layouts)/box/demos/box-layout.tsx" />

### Dimensions

너비와 높이를 설정하거나 최소/최대 크기 제약을 적용할 수 있습니다.

<Demo file="/content/docs/components/(layouts)/box/demos/box-dimensions.tsx" />

### Visual Styles

테두리 둥글기, 투명도, 텍스트 정렬 등의 시각적 속성을 제어할 수 있습니다.
