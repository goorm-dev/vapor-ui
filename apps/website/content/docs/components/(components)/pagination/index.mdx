## Property

### Sibling Count

Pagination에서 현재 페이지 주변에 표시할 페이지 번호의 개수를 설정합니다.

<Demo file="components/(components)/pagination/demos/pagination-sibling-count.tsx" />

### Boundary Count

Pagination의 시작과 끝에 항상 표시할 페이지 번호의 개수를 설정합니다.

<Demo file="components/(components)/pagination/demos/pagination-boundary-count.tsx" />
