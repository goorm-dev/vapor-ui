## Property

---

### Size

TextInput의 크기를 설정합니다.

<Demo file="/content/docs/components/(components)/text-input/demos/text-input-size.tsx" />

### Type

TextInput의 타입을 설정합니다.

<Demo file="/content/docs/components/(components)/text-input/demos/text-input-type.tsx" />

### Disabled

사용자가 상호작용할 수 없는 상태입니다. 액션을 수행하기 위한 특정 조건을 충족하지 않았거나 일시적으로 기능을 제한하려는 상황에서 사용합니다.

<Demo file="/content/docs/components/(components)/text-input/demos/text-input-disabled.tsx" />

### Invalid

유효하지 않은 상태(필수 항목 누락, 잘못된 입력 등)를 표시하여 올바른 입력을 유도합니다.

<Demo file="/content/docs/components/(components)/text-input/demos/text-input-invalid.tsx" />

### Read Only

값을 수정할 수 없지만, 텍스트를 복사하거나 읽을 수 있는 상태입니다.

<Demo file="/content/docs/components/(components)/text-input/demos/text-input-readonly.tsx" />
