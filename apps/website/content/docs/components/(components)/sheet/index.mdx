### Resizable

Sheet의 크기를 자유자재로 조절하길 원한다면 `<Sheet.ResizeHandle />`을 사용하세요.

조절 가능 영역을 제한하고 싶다면 `<Sheet.Popup />` 컴포넌트에 `min/max-height`, `min/max-width` 속성을 적용하세요.
