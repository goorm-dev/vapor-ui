## Property

---

### Open State

`defaultOpen`으로 초기 열림 상태를 설정하거나, `open`과 `onOpenChange`로 제어 모드로 사용합니다.

<Demo file="/content/docs/components/(components)/collapsible/examples/collapsible-open-state.tsx" />

### Disabled

Collapsible의 비활성화 상태를 설정합니다.

<Demo file="/content/docs/components/(components)/collapsible/examples/collapsible-disabled.tsx" />

### Keep Mounted

`keepMounted`를 사용하면 패널이 닫힌 상태에서도 DOM에 유지됩니다.
