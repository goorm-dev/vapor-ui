<Callout type="warn">
    `aria-label`은 필수입니다. IconButton은 아이콘 자식에 `aria-hidden="true"`를 자동으로 붙이므로,
    `aria-label`이 없으면 접근 가능한 이름이 비어 스크린 리더가 "버튼"이라고만 읽습니다. 아이콘이 뜻하는
    동작을 그대로 적으세요 — 예: `aria-label="Like"`.
</Callout>
