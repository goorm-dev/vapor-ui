## Related components

### Alert dialog vs Dialog

Alert dialog와 Dialog는 시각적으로 유사하지만, 접근성과 동작이 다르기에 명확히 구분해서 사용해야 합니다.

<DocsImage
    src="/composites/composites-문서-테스트-sk/images/related-components-01.webp"
    alt="Alert dialog vs Dialog"
/>

### Non-dialog

너무 잦은 Dialog 사용은 사용자의 주의를 분산시키고 반사적으로 Dialog를 닫는 행동으로 이어질 수 있습니다. 사용자의 결정이 프로세스에 영향을 주지 않거나, 중요도가 낮은 정보라면 비모달(Non-dialog) 컴포넌트를 사용하세요.
