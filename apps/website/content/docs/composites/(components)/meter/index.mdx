## Anatomy

<DocsImage src="/composites/meter/images/anatomy-01.webp" alt="Meter 아나토미 구조" />

| #   | Element    | Description                                                                                                                            |
| --- | ---------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Task label | Meter가 어떤 값을 나타내는지 설명하는 레이블입니다. 무엇을 측정하는지 알 수 있도록 항상 표시합니다.                                    |
| 2   | Value      | 현재 값을 숫자로 보여 주는 텍스트입니다. 백분율 또는 GB, 작업 시간 등을 표시하며 Indicator가 채워진 정도와 항상 같은 값을 보여 줍니다. |
| 3   | Indicator  | Track 위에 현재 값만큼 색이 칠해진 영역입니다.                                                                                         |
| 4   | Track      | Indicator가 채워지는 전체 영역입니다. 범위를 따로 정하지 않으면 0~100을 기준으로 합니다.                                               |

## Related components

### Meter vs Progress bar

Meter와 Progress bar는 시각적으로 유사하지만, 접근성과 동작이 다르기에 명확히 구분해서 사용해야 합니다.

<DocsImage src="/composites/meter/images/related-components-01.webp" alt="Meter vs Progress bar" />

| 구분       | Meter                      | Progress bar                                 |
| ---------- | -------------------------- | -------------------------------------------- |
| 사용 예시  | 사용자 수, 저장 공간, 용량 | 다운로드, 업로드, 업데이트, 데이터 로딩 처리 |
| 종료 시점  | 없음                       | 있음                                         |
| 애니메이션 | 없음                       | 있음, 작업이 완료될 때 까지 동작             |
