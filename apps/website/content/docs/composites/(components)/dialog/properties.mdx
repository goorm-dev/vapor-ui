### Dialog.Root

페이지 위에 창을 띄워 사용자를 중요한 정보에 집중시키거나, 특정 작업을 수행하도록 강제하는 Dialog의 루트 요소입니다.

<PropsTable part="dialog" />

### Dialog.Action

Dialog 문맥에 맞춰 `size`, `colorPalette`, `variant`를 고정한 주요 액션 버튼입니다. 그 외 Button prop(`onClick`, `disabled`, `type`, `ref` 등)은 그대로 노출됩니다.

<PropsTable part="dialog-action" />

### Dialog.Assistive

Dialog 문맥에 맞춰 `size`, `colorPalette`, `variant`를 고정한 보조 액션 버튼입니다. 그 외 Button prop은 그대로 노출됩니다.

<PropsTable part="dialog-assistive" />
