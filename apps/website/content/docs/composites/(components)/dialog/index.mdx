## Guidelines

### Height

Dialog의 최대 높이(Max-height)는 전체 화면 높이의 80%로 설정됩니다.

<DocsImage src="/composites/dialog/images/guidelines-01.webp" alt="Height" />

Close button:

Dialog는 헤더의 Close 버튼으로 닫을 수 있습니다.

Backdrop 클릭 / ESC:

배경을 클릭하거나 키보드 ESC를 눌러 Dialog를 닫을 수 있습니다.
