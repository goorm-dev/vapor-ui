# 리포트 템플릿

모든 컴포넌트가 **이 구조를 그대로** 따른다. 섹션을 빼거나 순서를 바꾸지 않는다. 해당 내용이
없으면 섹션을 지우는 게 아니라 "없음"과 그 사유를 적는다 — 빈 섹션은 정보고, 사라진 섹션은
누락처럼 보인다.


## 표기 규약

| 표기          | 뜻                                  | 쓸 수 있는 조건                  |
| ------------- | ----------------------------------- | -------------------------------- |
| `위임`        | 상류 라이브러리가 보장함            | **실측 근거를 함께 적었을 때만** |
| `조건부 위임` | 특정 prop 조합에서만 보장           | 조건과 미실측 조합을 명시        |
| `자체 구현`   | 상류가 안 함 — vapor가 보장         | —                                |
| `미확인`      | 실측 안 했거나 브라우저로 판정 불가 | 사유 필수                        |

`미확인`을 `위임`으로 올리지 않는다. 이 한 줄이 리포트의 신뢰 전부다.

## 섹션별 작성 규칙

### 헤더

`실측` 줄에 **prop 설정과 뷰포트를 적는다.** 같은 컴포넌트도 prop에 따라 판정이 갈리므로,
어느 설정에서 잰 값인지가 없으면 근거가 아니다.

### 1. 성질

**"붙지 않은 것"을 반드시 적는다.** 왜 `composite`가 아닌지, 왜 `transient`가 아닌지가
5번 제외 목록의 근거가 된다. 이 줄이 없으면 제외가 임의로 보인다.

### 2. 컴포넌트 책임

하위 4블록(`위임` / `조건부 위임` / `자체 구현` / `미확인`)을 전부 유지한다. 비면 "없음"과
사유를 적는다.

`실측 근거` 칸에 **관측한 값을 그대로** 적는다 — 속성값, 계산된 대비비, 픽셀 수치, 포커스가
간 요소의 텍스트. "충족함" 같은 요약은 근거가 아니다.

상류가 unstyled면 시각 축(1.4.3 / 1.4.4 / 1.4.10 / 1.4.11 / 1.4.12 / 2.4.7 / 2.5.8 /
KWCAG 5.4.4)은 예외 없이 `자체 구현`이다. 데모에서 잰 값은 기준선으로만 싣는다.

### 3. 공동 책임

각 행이 **prop 하나로 번역돼야 한다.** "aria-label을 받을 수 있게"까지 적고, 필수로 강제할지
여부는 6번으로 올린다.

### 4. 통합자 책임

Docs에 그대로 옮길 수 있는 문장으로 쓴다.

### 5. 제외

`sc-map.md`의 전역 제외 목록(페이지·사이트·플로우 수준)에 더해, **이 컴포넌트에서만 빠지는
것**을 1번의 "붙지 않은 것"과 연결해 적는다.

### 6. 설계 결정

여기 오는 것은 **답이 아니라 질문**이다. 리포트가 결정하지 않는다 — 리포트는 결정해야 할
목록을 만든다. 조건부 위임의 ⚠️ 항목과 공동 책임의 강제 여부가 여기로 올라온다.

### 참고

APG와 axe는 **각주에만** 둔다. 본문 표의 근거 칸에 들어가면 안 된다.
